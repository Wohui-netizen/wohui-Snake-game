# スネークゲーム（Web ページ）

[English](SKILL.md) · [简体中文](SKILL.zh-CN.md) · [Français](SKILL.fr.md) · [Русский](SKILL.ru.md) · **日本語**

## 目標

ユーザーが求めているのは、環境構築が必要なプロジェクトではなく、すぐに遊べるスネークです。既定では**単一の自己完結型 `index.html`** を交付します。HTML、CSS、JavaScript をすべてインラインにし、外部依存もビルド手順もネットワークリクエストもなくし、ダブルクリックで遊べるようにします。

「完了」とは、コードが書かれたことではなく、ユーザーがページを開いて実際に遊べることです。

## 固定仕様

ユーザーが明示的に別の希望を出さない限り、交付するページは次のすべてを満たす必要があります。

| 位置 | 要件 |
| --- | --- |
| 上部 | スコア行 `スコア: N　最高スコア: M` をリアルタイムに更新します。最高スコアはゲーム終了時に `localStorage` へ書き込まれ、リロード後も保持されます |
| 中央 | ゲーム領域: 正方形のグリッド盤面（既定で 20 × 20 マス）、薄い青緑の背景 + 白いグリッド線 + 濃い枠線。狭い画面では縮小して収まります |
| 下部 | 2 つのボタン: `ゲーム開始`（実行中は `一時停止`、一時停止中は `再開`、ゲーム終了後は `もう一度` に変わります）と `難易度: <現在の難易度>`（クリックするとすべての段階を順に循環します） |
| 蛇 | 2 つの目がある紫の頭、暗赤色の胴体。各胴体セグメントには進行方向を示す小さな矢印が付きます |
| 餌 | オレンジ色の四角形で、空いているマスにランダムに配置され、蛇と重なることはありません |
| 難易度 | 難易度が高いほど蛇は高速です。かんたん 220 ミリ秒、ふつう 150 ミリ秒、むずかしい 100 ミリ秒、地獄 60 ミリ秒／マス。ゲーム中に切り替えると即座に反映され、ヒント行に現在の 1 マスあたりの時間が表示されます |
| 敗北 | 頭が壁に衝突、または頭が蛇自身の胴体に衝突 → ゲームオーバー。オーバーレイに理由と最終スコアを表示します |
| 勝利 | 蛇がすべてのマスを埋める → 勝利としてゲーム終了し、以降は餌が出現しません |
| 操作 | 方向キーまたは WASD で旋回、Space で一時停止／再開。タッチではスワイプで旋回、タップで一時停止し、画面用の方向キーも表示されます。180° の反転は禁止です |
| 言語 | インターフェースは**英語（既定）**、简体中文、Français、Русский、日本語に対応し、ボタンの下に切り替え行があります。切り替えるとすべてのラベルが即座に変わり、選択は記憶されます。保存された値が不明または存在しない場合は英語にフォールバックします |
| ステータス | 待機中、一時停止中、ゲームオーバーの各状態では盤面上にオーバーレイを表示します。ステータス行は `aria-live="polite"` を使用し、すべてのボタンはキーボードで操作できます |

旋回はバッファリングが必要です。2 つの方向キーを素早く連続して押した場合（たとえば上→左）、各 tick が 1 方向しか読み取らないために 2 つ目が捨てられるのではなく、両方が反映されなければなりません。

## ワークフロー

1. **ファイルの置き場所を決めます。** 既定ではカレントワーキングディレクトリに `index.html` を書き出します。ユーザーがディレクトリやファイル名を指定した場合はそれに従います。対象ファイルがすでに存在する場合は、まずそれを読み、上書きするか、統合するか、別名で保存するかを判断してください。ユーザーがすでに持っていた内容を黙って破棄してはいけません。
2. **`assets/snake-game.html` から始めます。** 交付先のパスへコピーし、増分の変更を加えます。ゼロから書き直したり、返信に貼り付けたりしないでください。
3. **求められた箇所だけを変更します。** ベースラインのその他の挙動はすべて維持します。ベースラインには 5 つの変更点があります:
   - `COLORS`: 盤面、グリッド線、枠線、餌、胴体、頭、矢印、目。
   - `DIFFICULTIES`: 段階の一覧。`stepMs` が小さいほど高速です。ボタンは存在する段階をすべて循環し、既定の段階は `difficultyIndex` で決まり、段階の名称は `MESSAGES` の各言語の `difficulty` マップにあります。
   - `MESSAGES` と `LANGUAGES`: 言語ごとのすべてのインターフェース文言と切り替え行。6 つ目の言語を追加するには、`LANGUAGES` の項目を 1 つと `MESSAGES` の項目を 1 つ追加します。
   - `new SnakeGame(canvas, { cols, rows, cell, difficultyIndex })`: 盤面のマス数と 1 マスのピクセル数。キャンバスは実行時にマス数からサイズが決まるため、HTML の `width`/`height` 属性を手で編集する必要はありません。
   - 入力レイヤー: `KEY_DIRECTIONS` が方向キーと WASD を対応付けます。一時停止キーと「待機中は方向キーでゲームが始まる」挙動は `keydown` ハンドラーにあります。
   1 フレームあたり最大 4 ステップという追いつきの上限は維持してください。これを外すと、ユーザーがタブに戻ったときに蛇が一度に何十マスも進み、そのまま壁に突っ込みます。
4. **交付前に自己点検します。** 以下のチェックリストを項目ごとに確認し、可能であればコードから動作を推測するのではなく、実際にブラウザーでページを見てください。ベースラインは `window.SnakeGame`、`window.SNAKE_DIFFICULTIES`、`window.SNAKE_LANGUAGES`、および実行中のインスタンス `window.snakeGame` を公開しているので、ブラウザーコンソールから `snakeGame.tick()`、`snakeGame.setDifficulty('insane')`、`snakeGame.setLanguage('ja')`、`snakeGame.render()` で局面を操作・検査できます。
5. **引き渡しを説明します。** ファイルパス、開き方（ダブルクリック、またはそのディレクトリで `python -m http.server 8000` を実行し `http://localhost:8000/` を開く）、遊び方、変更内容を伝えます。

## 受け入れチェックリスト

構造と依存関係:

- 1 つの HTML ファイルで、`<script>` と `<style>` はインライン。`src`、`href`、`fetch`、CDN、Web フォントはありません。
- オフラインでもダブルクリックで遊べ、ブラウザーコンソールがクリーンです。

挙動（コード上だけでなく、ページ上で 1 つずつ確認してください）:

- `ゲーム開始` を押すと、現在の難易度の速度で蛇が進みます。
- `難易度` を押すと段階が循環します。同じ盤面で地獄はかんたんより明らかに速く、切り替えは即座に反映されます。
- オレンジ色の四角形を食べるとスコアが 1 増え、蛇が 1 セグメント伸び、餌が別の場所に再出現します。
- 頭が壁に衝突 → 理由が表示され、ボタンが `もう一度` になり、新しいゲームを開始できます。
- 頭が胴体に衝突 → 同じ敗北の経路をたどります。しっぽが直前まで占めていたマスには引き続き進入でき、誤判定は起きません。
- 蛇がすべてのマスを埋める → 勝利と判定され、以降は餌が出現しません。
- 反転のキーは何も起こしません。素早く連続して押した 2 つの正当な方向キーは、どちらも反映されます。
- Space で盤面が止まり蛇が進まなくなります。もう一度押すと再開します。
- 言語を切り替えると、スコア行、両方のボタン、オーバーレイ、ヒント行、ページタイトルのラベルが変わり、選択はリロード後も保持されます。保存された値が既知の言語でない場合は英語にフォールバックします。
- タブを離れて戻っても、蛇が何十マスも横断して衝突することはありません。
- リロード後も `最高スコア` は以前の記録を表示します（ブラウザーが永続化をブロックする環境では「クラッシュしない」への縮退で問題ありません）。
- 狭い画面（幅約 360 px）で盤面があふれず、ボタンと画面用の方向キーの位置がそろい、スワイプでも方向キーでも蛇が旋回します。

見た目: 全体の印象がリファレンスと一致します。上部のスコア行、青緑のグリッド盤面、オレンジ色の餌、矢印が付いた暗赤色の胴体セグメント、紫の頭、そして下部の 2 つのボタンです。

## リソース

- `assets/snake-game.html`: 実行可能な完全なベースラインゲーム。盤面の描画、スコア計算、難易度の段階、5 言語、一時停止、タッチ操作、アクセシビリティのヒントを含みます。読み通す文章ではなく、コピー元として使用してください。

## 境界

- Web スクレイピング、PDF、Anki のリクエストは範囲外です。ユーザーから依頼されたときは、その旨をはっきり伝えてください。
- フレームワーク、バンドラー、バックエンドを導入しないでください。オンライン対戦やランキングが必要な場合は、まずユーザーに確認し、別途設計します。
- ユーザーのブラウザー設定を変更せず、代理でインストールを実行しないでください。
